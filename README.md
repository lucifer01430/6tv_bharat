# 6TV भारत Static Frontend Theme

Production-style static frontend for a Hindi news portal.

## Structure

- `index.html`
- `pages/category.html`
- `pages/news-detail.html`
- `pages/latest-news.html`
- `pages/search.html`
- `pages/live-tv.html`
- `pages/videos.html`
- `pages/gallery.html`
- `pages/about.html`
- `pages/contact.html`
- `pages/404.html`
- `assets/css/style.css`
- `assets/css/responsive.css`
- `assets/js/script.js`
- `assets/images/`

The repeated header, navbar, breaking news, sidebar, footer, and search modal are intentionally repeated in static HTML and marked with Django-friendly comments for later conversion into includes.
